# Lyra Command Buffer Format

## Overview

The Lyra GPU executes work via command buffers generated by the CPU. A command buffer is a linear stream of 32-bit words interpreted by the command processor.

Execution is strictly sequential. There is no dynamic reordering.

Command buffers are immutable once submitted.

---

## Structure

A command buffer is composed of packets:
```
[HEADER][PAYLOAD...]
```

Each header defines:
- packet type
- length
- optional state flags

---

## Packet Types

| Type | Name |
|------|------|
| 0x0 | NOP |
| 0x1 | SET_PIPELINE |
| 0x2 | SET_VERTEX_BUFFER |
| 0x3 | SET_INDEX_BUFFER |
| 0x4 | SET_TEXTURE |
| 0x5 | SET_CONSTANTS |
| 0x6 | DRAW |
| 0x7 | DRAW_INDEXED |
| 0x8 | CLEAR |
| 0x9 | BIND_RENDER_TARGET |
| 0xA | SYNC / FENCE |
| 0xB | END |

---

## Packet Header Format (32-bit)
```
bits 31-24: packet type
bits 23-16: flags
bits 15-0: payload length (int 32-bit words)
```

---

## Core Packets

### SET_PIPELINE

Binds an immutable pipeline object.

Payload:
```
uint32 pipeline_id
```

---

### SET_VERTEX_BUFFER

Payload:
```
uint32 address
uint32 stride
uint32 format
```

---

### SET_INDEX_BUFFER

Payload:
```
uint32 address
uint32 index_type
```

---

### SET_TEXTURE

Payload:
```
uint32 unit
uint32 texture_id
uint32 sampler_state
```

---

### SET_CONSTANTS

Loads constant registers (C0–C255).

Payload:
```
uint32  base_index
uint32 count
fp24 data[count]
```

Constants are written sequentially.

---

### DRAW

Non-indexed draw call.

Payload:
```
uint32 vertex_count
uint32 first_vertex
```

---

### DRAW_INDEXED

Payload:
```
uint32 index_count
uint32 first_vertex
```

---

### CLEAR

Payload:
```
uint32 colour
uint32 depth
uint32 flags
```

---

### BIND_RENDER_TARGET

Payload:
```
uint32 framebuffer_address
uint32 format
uint32 width_height
```

---

### SYNC / FENCE

Used for CPU-GPU synchronisation.

Payload:
```
uint32 fence_id
```

GPU signals completion by raising an interrupt when reached.

---

### END

Marks end of command buffer execution.
